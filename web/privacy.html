Puedes consultar rutas sin proporcionar nombre o correo. La ubicación es opcional y sólo se solicita cuando activas una función que la necesita.

Responsable y contacto

Rutas Cancún es un proyecto independiente. Para solicitudes relacionadas con privacidad escribe a privacidad@rutascancun.com.

Datos que tratamos

  • Un identificador aleatorio generado en tu dispositivo para mantener una sesión anónima, proteger el servicio y asociar reportes comunitarios.
  • Ubicación aproximada o precisa, sólo con tu permiso, para centrar el mapa, mostrar rutas cercanas o calcular un recorrido.
  • Origen y destino elegidos, enviados por HTTPS a nuestra API para calcular alternativas.
  • Reportes voluntarios: ruta, tipo de reporte, coordenadas, fecha e identificador anónimo.
  • Datos técnicos básicos que la infraestructura pueda procesar, como dirección IP, agente de usuario y registros de seguridad.

Finalidades

Usamos esos datos para entregar las funciones solicitadas, mejorar la precisión, mantener sesiones anónimas, prevenir abuso y resolver fallos. No vendemos datos personales ni usamos la ubicación para publicidad.

Proveedores necesarios

El mapa utiliza CARTO y datos de OpenStreetMap. El buscador usa Photon para procesar el texto escrito y devolver sugerencias. La infraestructura y protección web pueden operar mediante Cloudflare. Estos proveedores pueden recibir datos técnicos como la dirección IP conforme a sus propias políticas.

Conservación y seguridad

La comunicación con nuestra API usa HTTPS. Conservamos identificadores anónimos y reportes mientras resulten necesarios para operar, proteger y mejorar el servicio, o hasta que proceda una solicitud válida de eliminación. Los puntos utilizados únicamente para calcular un viaje no se guardan como historial personal de viajes.

Tus decisiones y derechos

Puedes negar o revocar el permiso de ubicación desde Ajustes de Android. Puedes solicitar acceso, corrección o eliminación escribiendo a privacidad@rutascancun.com. Podremos pedir información técnica mínima para localizar el identificador correcto.

Menores y cambios

La app está dirigida a personas de 13 años o más y no está diseñada específicamente para menores de 13 años. Publicaremos cambios materiales en esta página.
